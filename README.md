# Pogodi broj

Mala web igrica: računalo zamisli broj od 1 do 100, a ti ga pokušaš pogoditi u što manje pokušaja.

**Igraj ovdje:** https://ivan08012.github.io/pogodi-broj/

## Kako se igra

1. Upiši broj i klikni **Pogađaj**.
2. Igrica ti kaže treba li broj biti **veći** ili **manji**.
3. Traka pokazuje u kojem rasponu je još traženi broj.
4. Najbolji rezultat se pamti u pregledniku.

Cijela igrica je jedna datoteka, `index.html`. Otvori je u bilo kojem pregledniku i radi bez interneta.
